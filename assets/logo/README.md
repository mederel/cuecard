# Logo

Concept A, "Fade": a card whose lines fade out as you learn them. The gold dot is the cue.

- `cuecard-mark.svg`: the mark, for light backgrounds.
- `cuecard-icon.svg`: the app icon (rounded square, mark inverted).

Palette: ink `#1E1B3A`, cream `#F7F2E8`, gold `#F2B544`. The wordmark is "cue" in bold over "card" in regular, set in Fraunces (SIL Open Font License); it is not committed as a file.
